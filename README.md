# Colab support

Colab is an independent Python job integration by ailuntz. Connect your own Google account to run parameterized jobs on Google Colab, inspect their results, and rerun them with different parameters.

- [Product website](https://colab-jobs.ailuntz.com/)
- [Get support](https://github.com/ailuntx/colab-jobs/issues)
- [Privacy policy](privacy.md)
- [Terms of service](terms.md)

For a problem report, describe the action, what you expected, and the error message with personal data removed. Keep code, results, job identifiers, email addresses, passwords, tokens, and other private data out of public issues. For an account or data removal question, ask for a private follow-up.
