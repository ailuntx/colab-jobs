# Colab terms of service

Effective November 21, 2026. Colab is an independent Python job integration operated by ailuntz. It connects your Google account to run your code in Google Colab.

Use only accounts, code, and data that you are authorized to use. Follow the [Google Colab usage limits](https://research.google.com/colaboratory/faq.html) and the applicable [Google API terms](https://developers.google.com/terms). Jobs consume resources under the account you connect. Runtime availability and limits are set by Google.

Keep independent copies of important code and results. Jobs can fail or be interrupted by runtime, quota, network, or service conditions. Access may be suspended for misuse. You can disconnect in ChatGPT or revoke the authorization in Google Account settings.
